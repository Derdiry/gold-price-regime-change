# Sudan gold price data

**The full Sudan file (`data/raw/new_Data.csv`) is not included in this repository. Full data available on request from the author, for research purposes.**

`new_Data_SYNTHETIC_sample.csv` holds **20 SYNTHETIC rows** in the identical schema. No value in it is real. It is generated by `scripts/make_synthetic_sample.py`: every numeric column is an independent seeded random walk, no relationship between columns is modelled, and the dates (January 2000) lie outside the real sample period. Use it only to see the file format.

## Source

Official reference prices for Sudanese 21-karat gold (2015–2022), obtained by the author; not redistributable; available on request for research purposes. This is the dataset of Wan & Elbushra (2024), ICCNC 2024, pp. 71–78, doi:10.1109/ICCNC63989.2024.00020.

## What the series is

The Sudan series is an official reference price that moves almost one-for-one with the official SDG/USD exchange rate (R² of log price on log exchange rate = 0.9976, OLS on the 1425 observed rows; `results/summary/facts.md`), so forecasting it largely means forecasting the official exchange rate.

## Description of the real file (`new_Data.csv`)

- 2528 rows, 2015-01-06 → 2022-12-22 (`results/summary/facts.md`, `results/data/split_summary.md`).
- Irregular dates: 635 dates have several quotes (the first quote is kept, leaving 1425 dated rows), and there is a 404-day gap from 2019-11-25 to 2021-01-02.
- One decimal-shift outlier: Open = 117472 on 2016-12-03, restored to 1174.72 at load time (`src/data/quality.py`).
- Columns:
  - `date` (d-Mon-YYYY)
  - `Price` (local price, SDG per gram of 21-karat gold)
  - `P/O 24` (international price, USD per troy ounce)
  - `p/g 21` (USD per gram of 21-karat gold)
  - `local USD` (official SDG per USD)
  - `Open`, `High`, `Low`, `vol` (international daily open/high/low and volume)
- SHA-256 of the real file: `14d6d75508467435f7cc6b11386343223b79de795cae3347db1c9b6f50039522` (`data/processed/v2/data_manifest_sudan.json`).

The code, configuration, tests, result tables and preregistrations in this repository are complete. Rebuilding the Sudan data, retraining, or running `scripts/report_splits.py`, `scripts/project_facts.py` or `notebooks/01_data.ipynb` needs the full file.
